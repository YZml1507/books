## 0. 一句话结论

「泛泛」的根因不是文案不够好，而是**结构性地不许说判词**：
(a) 所有信号行只报坐标不敢给判断；
(b) LLM 双封印——system prompt 明禁「克/必离」词 + 出站闸 `_BANNED_OUT_PAT`
把 `相克|相刑` 当恐吓词杀；
(c) 没有「信号→生活面矛盾」的翻译层，想说具体也没素材；
(d) 交权句（「靠你们自己写」）是空地图交权——零选项零代价。
修法不是重写文案，是**加一层确定性判词引擎**：信号→判词→生活面
矛盾预言→条件化解→带地图交权，全部确定性模板（引用真实学理），
LLM 侧同步解封技术词并把判词素材喂进 facts。

## 1. 调研结论摘要（三路 agent）

### 1a. 行业写法（agent 7ac126f3）
- 行业标准结构：总判词→分项依据→矛盾剧本→时间窗→化解动作
  （准了合盘报告明列「关系破裂的原因」为卖点）。
- 「说到我心里」的可复用手法：判词挂锚点/敢下单边判词/预言矛盾
  主题/if-then 动作处方/验证锚点/带地图的交权。
- **可互换性测试**：一段话换给另一对用户还成立 = 泛的。每条解读
  必须含本次输入独有要素。
- 交权错误姿势：「关系靠你们自己经营」=零信息甩锅；正确姿势 =
  列出各路径真实代价+无论选什么都做得动的微动作（SDT 三要素）。

### 1b. 传统学理（agent aad19d26）
- 可直接落模板的判词资产：
  - 日支相冲按五行分三型：水火（子午/巳亥）=急性争吵型、两土
    （丑未/辰戌）=冷战较劲型、金木（寅申/卯酉）=硬碰硬原则型。
  - 五行相克五型：金克木=批评与自由、木克土=进取与安稳、
    土克水=管控与自由、水克火=冷热错频、火克金=冲动与界线。
  - 年柱/属相六冲→双方家庭与买房养老育儿长辈相处；六害=暗伤
    消耗型（断头婚歌诀）；相刑分型（无恩/恃势/无礼/自刑）。
  - 《神峰通考》「比劫男配伤官女此系合婚之正理」——单方硬伤
    恰是互补原料的反转逻辑。
  - 吕才合婚三等分级 + 「中等婚凶少吉多则可」「合婚十全者寥寥」
    等传统自带的分级话术。
- 交权正解：传统自带「解」通道（通关五行/晚婚/远亲近疏/择吉），
  判词+落日子+条件例外三段式本身就是把判断权还给用户。

### 1c. 代码病灶（自审补充）
- `warm_hehun`：报信号不给判词，「相克→磨合期长一点最扛事」、
  「无冲无合→靠你们自己写」是用户点名的问题本体；`match_score`
  （确定性 35–99）算出却从不进文案。
- `_BANNED_OUT_PAT` 禁 `相克|相刑`、polish `_SYSTEM` 禁「克/必离」
  →LLM 径双重封印，只能吐软话。
- FE 合拍指数 ≥85 有庆祝档、低分裸数零解读（不对称）。
- `facts_hehun` 无分数/无判词/无矛盾预言——模型无素材可说具体。

## 2. 设计：「判词引擎」四件套（确定性）

```
信号 → 判词（直说级）→ 矛盾预言（生活面）→ 条件化解 → 带地图交权
```

### 2.1 合婚判词带（match_score 锚 + 硬伤升级）
- ≥80 且零硬伤「上等合拍」/60–79「中上磨合」/45–59（或硬伤≥2）
  「磕绊偏多」/<45（或硬伤≥3）「判词直说：偏不合适」——
  分档与吕才三等婚话术对齐（band 命名随 voice.py 实现，R3265 同步）；
- 硬伤单项可拉档：日柱天克地冲/日支冲+相克叠加/断头婚类信号
  出现时判词不再按分说话（「书上对这种组合的判词是——」直引歌诀）。
- 每档判词**必须挂锚点**（「日支 寅/申 相冲，金木相战」点名坐标）。
- 相克盘判词直说：「两人日主五行相克——相克就是相克，书上不
  绕弯，矛盾会在 X 面长出来」+「但合婚十全者寥寥（《婚元通书》
  口径），硬走会撞的具体问题在下面」。

### 2.2 矛盾预言表（信号→生活面）
按 1b 调研建 `_HEHUN_FRICTION` 映射，逐信号给「会为什么吵」：
- 日支冲：按两支五行归类（水火/两土/金木）→三种矛盾形态；
- 日主五行相克：按十组合查表→五型摩擦（金克木=批评与自由…）；
- 年支六冲→双方家庭线（买房/养老/育儿/长辈相处）；
- 大运背离→节奏错位（财务决策/人生重心）；
- 桃花同支→不是矛盾是期待同频（正面预言也给具体的）。
每条预言附「典型剧本」一句（例：冷战型→「谁都不先低头，
翻旧账；家务分工、买房置业上长期较劲」）。

### 2.3 条件化解（传统自带的解通道）
- 信号负但另有正信号中和 →「这组凶有解」句（神煞相抵口径）；
- 无相抵 → 传统化解位：通关思路/相处处方 if-then 一条
  （调研手法 9：「如果他开始沉默超过两小时，你只发一句…」）。
- 绝不写「只要相爱就能克服」——改写「这段关系的成本在 A/B
  两处，值不值只有你知道」。

### 2.4 带地图交权（收口替换「靠自己写」）
- 结构：走下去的代价（点 1–2 个真实摩擦面）/换一条路的代价
  （一句话，不劝分不劝和）/一个无论选什么都做得动的微动作。
- 尾句固定口径：「命理给的是你们会被反复考验的点，不是判决书。
  看清楚了还愿意牵手，是你们自己的本事。」（调研收口句）

## 3. LLM 侧解封与素材供给

- `_BANNED_OUT_PAT` 摘除 `相克|相刑`——技术判词词不再是恐吓词
  （命令词 必离/没戏/克夫/克妻/注定/赶紧分/断联 等保持禁）。
- polish `_SYSTEM` 改判词规则：「盘面事实里的相冲/相克照说，
  但每个负向点必须带（a）具体矛盾面 （b）『这是倾向不是定数』
  口径；不许把判词升级成断言（注定/必离仍禁）。」
- `facts_hehun` 补：合拍指数+判词档+矛盾预言行+硬伤到判词的
  确定性映射行——模型拿到的就是成品判词素材，不靠自己编。
- chat system prompt 同款改判词规则（陪聊里「我们八字相克吗」
  不许再绕开答）。

## 4. FE 分数展示对称化

- ≥85 庆祝档保留；≤49 加诚实档：「这分偏低——判词看下面，
  别只看数字」；50–84 中性不标。
- one_liner 分桶已存，改用判词档盐键（低分不抽「细水长流」）。

## 6. 红线

- 判词硬≠宿命断言：每个负向判词必须同时带 (a) 锚点 (b) 具体
  矛盾面 (c) 条件/化解 (d) 交权句。「注定/必离/没戏/克夫」仍禁。
- 医疗/危机/敏感边界不动（#20–#24 安全族不回退）。
- 学理引用标注来源口径（「传统上说」「书上的判词」）不伪称
  科学预言；判定依据全部来自已算出的字段，不发明新信号。
- 未成年/同人盘等既有校验不动。
- FE/BE 场景词 parity 保持钉扎；老 Safari 兼容（无 lookbehind）。
