## 0. 一句话结论

从「命理工具站」重塑为「和朋友分享的每日小确幸 App」：
内容芯（确定性排盘 + 古籍引证）是护城河保留不动，
表达层（文案口吻 / 视觉 / 功能组织 / 动效）全部按目标用户重做。

## 1. 用户画像与设计原则（WHY）

主用户：15–24 岁女性，小红书重度用户。她们转发一张图的条件是
「好看 + 说我心里的话 + 我不好意思说出口的它替我说了」。
她们弃用一款产品的条件是「说教感 / 爹味 / 生硬术语 / 长表单」。

由此四条设计原则（每条对应下面的 US）：

| # | 原则 | 反面（现状） |
|---|---|---|
| P1 | 说人话：像闺蜜转发语，不像说明书 | 「你自己心里有数」「盘里有着落点」类句式仍有生硬残留 |
| P2 | 视觉即内容：牌面/卡片/海报本身就是可转发的成片 | 塔罗牌面 v1 只是「有符号」；首页背景仍是纯色渐变 |
| P3 | 一个疑问一条路径：按意图给唯一入口，不摆 8 张表单 | 合婚/桃花/排盘三个入口本质同一引擎，重复感强 |
| P4 | 惊喜感：微动画、抽牌仪式感、每日开盲盒体验 | 仅塔罗有翻牌动画；其余功能提交后直接出结果 |

## 2. User Stories（WHAT——每条含可测量判据，HOW 留 plan）

### US1 文案全面体检（P1）
**作为**目标用户，**我想要**所有文案像朋友说话，**以便**不被说教感劝退。
- 判据：建立禁语清单（说教式第二人称指令、「你自己…」句式、术语裸奔），
  selftest 增量断言 warm 全量输出零命中；现有三处改写
  （「心里有数」「你比盘清楚」「你自己舒服最重要」）作首批准入样例。
- 边界：免责声明语义必须保留（「仅供娱乐」不可删），但措辞软化。

### US2 塔罗牌面 v2 与抽牌仪式感（P2）
**作为**目标用户，**我想要**抽牌像拆塔罗牌盲盒，**以便**截图发小红书。
- 判据 a：78 张牌每张有可辨识差异的插画元素（v1 的 emoji 方案升级为
  程序化 SVG 场景：底纹 + 意象构图 + 数字/花色徽记）；
- 判据 b：洗牌→切牌→翻牌三段动画 ≤3s 且长任务 0（复用 T3.3 口径）；
- 判据 c：结果区一键生成竖版分享图（对齐 shareBazi 模式，判据 12/13 口径）。

### US3 功能谱系重组（P3）
**作为**目标用户，**我想要**「我想问什么」直达唯一入口，**以便**不用分辨八个相似功能。
- 方向：八字系（排盘/合婚/桃花/起名）合并为一个「命盘」入口下的四个 tab
  （数据同源：一次输入四人共用）；塔罗/六爻并为「问一卦」双卡；
  黄历并入「今日」簇。首页功能卡 8 → 3 大入口（今日/命盘/问一卦+读书）。
- 判据：入口数、各 tab 数据一致性（同输入同盘）、ui_smoke 用例映射更新；
  旧 8 视图路由保留一个版本期（重定向不 404）。
- ⚠ 此条动信息架构与探针导航路径，需独立一轮 + 探针同步改造。

### US4 首页视觉重塑（P4）
**作为**目标用户，**我想要**打开页面就有「今天也值得记录」的感觉，**以便**每天想点开。
- 方向：背景从纯色渐变升级为「时辰感知」氛围（晨昏色调随访问时间变化，
  CSS 变量驱动可回滚）；卡片圆角/阴影/留白按 003 令牌体系统一提级；
  每日运势卡增加「今日开盒」交互动画。
- 判据：对比度仍全 AA（003 判据 3）、横向溢出 0、FCP 不慢于基线、
  reduced-motion 下动画数 0（全部沿用 003 既有量尺）。

### US5 分享即增长（P3×P2 交叉）
**作为**目标用户，**我想要**每个功能的结论都一键变成好看的小红书尺寸图，**以便**愿意发笔记。
- 现状：排盘/起名/桃花/合婚已有海报（R193b）；daily/塔罗/六爻无。
- 判据：六端点全覆盖海报出口；统一模板族（同色板不同版式）；
  check_poster 口径逐端点复用。

## 3. 非目标

- 内容芯不动：确定性排盘算法、引文契约（宪法第三条）、eval 体系原样。
- 不引入外部图片/字体/CDN（宪法第二条红线 3 持续生效）。
- LLM 润色层保持 additive（D-251b 既有决策）。

## 4. 排期建议（依赖关系）

US1（纯文案+selftest，轻）→ US2（前端为主，中）→ US4（CSS 为主，中）
→ US5（复用海报管线，轻）→ US3（动架构+探针，重，单独一轮）。
