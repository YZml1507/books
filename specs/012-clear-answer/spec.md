# specs/012 — 「明确的答案」：从描述层到方向层

> 立项：R3125（2026-09-27）。用户反馈「解读仍然不深刻、没猜到用户想要什么、
> 用完不知道该怎么做」+「小满回复和卡面判词有时候不一样」。
> 本 spec 先全网调研后成文——调研对象：测测/Co-Star/陶白白等头部产品
> 与命理博主话术结构、传统命理师断命流程、AI 算命提示词工程实践。

## 调研结论（为什么别人显得「准」且「有用」)

1. **可验证锚点链**（江湖话术拆解，英耀篇/阿宝篇）：先断过去/现状
   （说中已发生的取得信任）→ 具体意象 → 数字方位锚 → 应期 → 脱罪
   （归到运不归到人）。每句都有可对号入座的抓手。可学的部分是
   **结构**（先验后断、具体锚点、情绪赦免、行动指令），不是骗。
2. **场景重演**（陶白白）：写具体生活场景白描（「天蝎看到同事
   窃窃私语就觉得在阴阳自己」），读者自己脑内对号入座。「准」是
   场景粒度不是形容词粒度。
3. **直断+祈使**（Co-Star）：用户嫌 emoji 含糊后改成直接祈使句
   （"Check your ego""Take yourself out to dinner tonight"）——
   明确方向 > 委婉描述，像酷姐姐不像导师。
4. **贴着盘问**（测测）：AI 问答以星盘档案为数据底座，预置问题
   全部基于用户档案，档案对象可切换——不做泛聊天机器人。
5. **命理师正规流程**：定喜忌→断性情→断大运（整体→分域→心态→
   最可能的事）→断流年→给建议（看命的目的是改变）。终点永远是
   行动。
6. **AI 算命工程实践**：确定性计算外包给代码、AI 只做翻译与人话；
   回答必须明确指回输入字段（宫位/星曜锚定）。我们的架构本就如此，
   优势在——差的是「口径一致性」与「答案的方向感」。

## 差距诊断

| 层 | 现状 | 差距 |
|---|---|---|
| 判词 | 有判词带/剧本/处方/交权 | 剧本是概括性短语，不是 48h 时间线场景重演 |
| 应期 | 大运/桃花应期/下个宜日数据都在 | 没整合成「什么时候会变」的时间轴输出 |
| 行动 | 处方单行 | 应为「先做→观察信号→若X则Y」三段式 |
| 抓手 | 方位/吉色/吉时散落在各层 | 没汇成一条「可借力的具体抓手」 |
| 信任 | 先给结论 | 缺「先验」位——先用盘上可自验的现状断言立信 |
| 赦免 | 交权行有「命理给地图」 | 缺明确的「这不怪你，是运/盘的事」脱罪位 |
| chat | 判词走「话题参考」降权框 | 模型可自由发挥与判词矛盾（实测复现） |
| 泛问 | 「今年怎么样」→ 不瞎编 | 时间向问题是流量最高的问法却被拒答 |

## 方案

### P0 chat 判词权威信道（已落地 R3124b/c）
- 各端点响应带 `result_ref`（服务端结果快照内存缓存，TTL 2h）
- chat 带 ref → 服务端从**自己的缓存**提取判词原句进 system
  权威块：「与卡面逐字一致，不许反驳不许软化」
- 成稿一致性闸：回复与判词方向矛盾 → 纠偏重试一次 →
  仍矛盾则按判词原句确定性兜底
- 伪造 ref 只能拿到空集（服务端缓存里没有就是没有）

### P1 意图路由补全（已落地 R3124a）
- 时间向/泛向问题（今年/最近/运势/帮我看看）→ 眼下运+
  流日气候+五行底色三层确定性回答；跨年问法在 scope=day 时
  指路「一生」范围
- 真识别不了的（养猫/颜色）仍如实「不瞎编」——底线不破

### P2 「先验位」+场景重演（待做）
- warm.reply 首行后插一条**可自验现状断言**（日主/五行/眼下运
  推出的性格或近况断言），先让人点头再下判词
- hehun 冲突剧本升级为 48h 时间线重演：起争执的引信→
  各自的心理活动→第二天的状态（按相克对/五行对逐对写）
- taohua/liuyao/tarot 同结构：把「在哪、什么形式出现」写实

### P3 应期时间轴（待做）
- 各判词卡统一一行「时间轴」：眼下运剩余年数/下一运换班年、
  桃花应期窗口、黄历下个宜日、流月提示——全部取已有确定性字段
- chat facts 同步带应期行

### P4 三段式行动卡（待做）
- 处方升级：「先做 X（具体到动作）→ 观察信号 Y → 若出现 Z 就怎么调」
- 借力抓手行：方位（桃花支方/日支合方）+ 幸运色（day_luck
  lucky_colors）+ 时间窗——标注「民俗抓手，图个顺手」

### P5 脱罪位（待做）
- 负向判词统一带「归因给盘不给你」一行——「前几年没成不是你
  的问题，是忌神运压着」式心理补偿，但只用盘上算得出的归因子
- 与交权行合并去重（不交权两遍）
