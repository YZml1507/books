# R31–R35 规划（调研周期 5）

> 调研时间：2026-10-01  
> 依据：Nomi/Replika 记忆架构、Fabulous 微仪式、Just One Win 小确幸、
> 2026 中国 AI 算命/赛博玄学情绪消费。

## 关键新判断

1. **可见记忆比隐藏记忆更动人**：Nomi 让用户看到 147 条共享笔记，
   Replika 摘要情感但不可见。小满应该把「小满知道的事」做成一
   块用户能展开的事实板。
2. **微仪式是 habit forming 的最小剂量**：Fabulous 把喝水/呼吸
   堆成故事化 micro-rituals。小满日签已有「宜试试」——把它变成
   一个可点击「做完了」的今日仪式。
3. **小确幸日记只问一句话**：Just One Win 模式。用户不需要写长
   日记，只需回答「今天一件小事」即可打破抑郁退缩循环。
4. **赛博玄学的本质是电子树洞 + 社交货币**：18–30 岁占 70%，
   付费率低但传播率高。继续强化「可截图/可转发」的短内容。
5. **PWA 离线兜底仍弱**：无网时打开应给出缓存页，而不是白屏。

## R31–R35 行动

| 轮 | 项 | 内容 |
|---|---|---|
| R31 | 记忆事实板 | 聊天空态新增「小满知道」折叠块：列出我的档案生日、最近事由、近 7 天心情主色、最爱问的功能。让用户看见自己被记住。 |
| R32 | 今日仪式 | 日签卡「宜试试」变成可点「✅ 做完了」的今日仪式，点击后本地记录，不打卡不断签。 |
| R33 | 今日小确幸 | 首页或聊天空态问「今天一件小事」并本地保存 `journal:<date>`；只一句，不写长日记。 |
| R34 | 分享落地优化 | `?from=share` 深链到达时，首页顶部给「看看 TA 的签 · 你也来一份」的轻提示，提高裂变转化。 |
| R35 | 离线兜底 | sw.js 增加 `/` 与核心静态资源预缓存；无网打开时显示「小满offline卡」而非白屏。 |

## 不做的事

- 不做长日记/复杂编辑器。
- 不做付费解锁/会员订阅。
- 不做 streak 惩罚或补签。
