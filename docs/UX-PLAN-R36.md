# R36–R40 规划（调研周期 6）

> 调研时间：2026-10-01  
> 依据：记忆可编辑/暂停控制（Aeliana/Nomi）、微庆祝反馈（MicroWins/Confetti）、
> PWA Push 软提示、AI 算命「半信半疑」社交货币。

## 关键新判断

1. **记忆必须可控制**：Aeliana/Nomi 让用户 review/pause/clear memory。
   小满的事实板下一步要长出「让小满忘掉这个」控件。
2. **做完一件小事需要即时反馈**：Confetti/MicroWins 用微庆祝把
   微小行动变成多巴胺小高峰；Ritual/Journal 点击后应该给一颗星星。
3. **Push 软提示优于自动弹权限**：先问价值再弹浏览器权限。
4. **玄学用户要社交货币**：每周/里程碑要有一张可截图的「小满周报」。
5. **久归要深拥**：超过 3 天没打开，首页给一句「你不在的日子小满也在」。

## R36–R40 行动

| 轮 | 项 | 内容 |
|---|---|---|
| R36 | 微庆祝 | 日签仪式「做完了」和日记「记下」后加一颗飘出的 ✨ 星星动画，持续 0.8s，不打扰但即时反馈。 |
| R37 | 记忆可忘 | 事实板每个事实后加「× 让小满忘掉」按钮，只清该键（生日→清空 me；事由→删单条 chat:topics；心情→清当天 mood）。 |
| R38 | Push 软提示 | 设置页或聊天空态加「让小满轻轻叫我」开关，点击后说明用途再调用 Notification.requestPermission。 |
| R39 | 小满周报分享卡 | 每周一自动生成「上周小满看见你 X 次」周报海报，含心情主色/常问功能/完成仪式数。 |
| R40 | 久归深拥 | 首页根据 `usage:last` 计算缺席天数，≥3 天在顶部 banner 给「你不在的日子小满也在，今天想测什么？」 |

## 不做的事

- 不做 streak 惩罚、补签、付费墙。
- 不做服务器 push 订阅（本地 permission 探索即可）。
