## §1 发现清单（按轮次追加）

### F-01 selftest 在语义路径上崩溃而非干净降级（CRASH，待修）

- 现象：`BOOKS_LLM_DISABLE=1 python3 web/selftest.py` 退出码 1，
  崩在 `web/selftest.py:507`（bazi.semantic）→ `src/guji/bazi_lookup.py:316`
  `np.load(SEM_DOCVECS)` 抛 `ValueError: This file contains pickled (object) data`。
- 根因：`data/catalog/bge_mingli_docvecs.npy` 在未 `git lfs pull` 时是 132 字节
  **指针文件**，`os.path.exists()` 对它返回 True → 缓存命中判断通过 →
  `np.load` 读指针文本崩溃。README 明示「web 主路径不依赖它，没拉也能正常用」，
  实测与之矛盾（文档-实测冲突，照宪法 I 应记录并修）。
- 影响：selftest 375 项中第 ~1/3 处整体中断，后续检查全部无法执行——
  回归检测能力在无 LFS 环境完全失效。
- 修复方向（待实施）：`_sem_vecs` 的缓存校验增加「实体性」判断
  （load 失败/文件过小即视为缓存未命中），并在模型不可得时给出
  可读的降级提示；selftest 侧将 bazi.semantic 在模型缺失时标
  SKIP(env) 而非静默 pass（参照 probe 既有 skip 惯例）。
