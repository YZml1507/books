# 战略方案：小满的解忧铺该往哪走

> 竞品调研 + 定位裁决 + 三阶段路线图（R3249）
> 数据截至 2026-09；外部数字均为公开报道口径，标注出处。

### 趋势信号

- **DeepSeek 算命潮**（2025.2 微信相关帖子 200 万+）：推理模型的结构化推理天然契合八字——证明"AI×命理"是真需求不是伪风口

## 二、我们的真实位置（不吹不黑）

### 手里有的（别人没有/难抄）

1. **引文可核验的确定性内核**：47 部古籍、62k+ 语料单元，引文到原文锚点。测测的心元大模型本质是生成模型，照样会编；我们事实层零幻觉。**这是全网唯一性卖点**，FlowPix 那篇实测文章恰好验证了这条路线的必要性。
2. **个人判词分层**：通判（黄历口径）+「对你」冲合层 + 十神日标签——同一天不同人开出不同签。大多数竞品的每日运势还是十二星座十二句。
3. **工程纵深**：375 自检 / 726 契约 / 91 浏览器冒烟 / 三节点 LLM 竞速降级——这个工程质量在单人项目里是超配的。
4. **隐私本地化**：localStorage 档案、可离线、无账号——在小红书人群里反而是卖点（生辰是敏感信息）。

### 手里没的（竞品的真实壁垒）

1. **账号与云同步**：换机/清缓存即丢档——留存漏斗的底漏了
2. **社交裂变闭环**：合盘只有"邀请链接"雏形；测测的好友合盘、The Pattern 的伴侣互看才是增长引擎
3. **推送触达**：PWA push 在国内安卓生态基本不可用——Co-Star 靠推送日活，我们没有召回通道
4. **变现路径**：零付费点
5. **内容运营**：没有 feed、没有话题、没有可晒的固定栏目
6. **合规风险**：目前"文化与技术探索"定位正确，但"算命/占卜"字眼在应用商店和社交平台都是敏感带

## 三、定位裁决

**不做测测平替**——2.5 万咨询师、4500 万用户、备案大模型，正面打不过也没必要打。

**做"古籍有据可查的那一个"**：当所有人都在用生成模型编漂亮话，我们是唯一能指着原文说"这句出自《诗经·郑风》"的产品。玄学市场的信任危机（AI 瞎编）越大，这个位置越值钱。

一句话定位：**「小满的解忧铺——你的八字，有据可查」**

### 不该做的（明确否决）

- ❌ 真人咨询师市场/连麦咨询——重资产、要资质、和测测正面刚
- ❌ 大而全星座社区——单人维护不动 UGC
- ❌ 紫微斗数等重排盘扩展——投入产出比低，爱好者工具已够用
- ❌ 原生 App 重写——PWA 形态继续，把"能装到桌面"做扎实

## 四、三阶段路线图

### P0 · 现在～共创 Demo（进行中）

- Atria 共创计划投稿（已完成申请文案）
- 守住现有工程质量闸门全绿
- 核心叙事固化：**「AI 讲故事但不许编」**——典故点评、判词润色全走"事实层给定+模型转述"

### P1 · 传播闭环（下一阶段重点）

产品是奶奶辈都能用的形态了，缺的是**让人能把结果晒出去**的回路：

1. **分享图已是基础设施**（本周签运/星座速配 PNG 已能导出）→ 下一步：每张图带一句"这句话出自《诗经》XX"的可核验钩子 + 落地页深链 `?ref=share`，让点击者直接落到自己的判词
2. **"你的名字出自《诗经》哪句"专题**——小红书天然话题钩子，点评结果页一键出分享图
3. **Co-Star 式每日钩子文案**：判词第一句写成"适合直接转发"的短金句（伏吟日="老事回锅日，别硬开新局"），文案池按判词分档轮换
4. **召回通道**：PWA push 不可用 → 改做"明日预告"停留钩子（已有"明天吉·记得来拆明天的礼物"）+ 可选订阅邮件/公众号渠道调研

### P2 · 留存深化

1. **账号轻同步**：可选手机号/邮箱登录，把 localStorage 档案上云（保留"不登录也能全功能"——隐私人设不破）
2. **小满记忆深化**：已会记你的盘；下一步记"你问过的事"——"上次你说要换工作，这周签正好是变动位"——回访钩子的最高形态
3. **双人合盘升级**：从"邀请链接回填"到"关系谱"——保存过的合婚对象列表，每日"今天你们俩的合拍度"

### P3 · 变现（远期，不承诺）

按变现效率排序，都不需要真人供给：

1. **深度报告**（FateTell 验证过 $39.99 能卖）：年度流年书/起名详批——我们出"可核验版"，每个引文附原文锚点截图位
2. **起名付费包**：候选名从 6 个到 60 个 + 典故点评 + 分享海报
3. **礼物盲盒机制**：每日签里抽实体周边兑换（轻电商，Astrotalk Store 的迷你版）

### 合规红线（贯穿全程）

- 所有页面维持"文化与技术探索·不构成人生建议"口径；对外物料用"古籍智慧""情绪陪伴"措辞，避开"算命/占卜/预测"表述
- 生辰数据明示本地存储/可控删除；上架任何商店前补完整隐私政策
- 不碰未成年人、医疗、重大决策建议场景的引导性文案

## 五、要不要重构

**不需要推倒。** 当前架构（确定性内核 + LLM 增量层 + PWA 壳）恰好是竞品验证过的正确形态：

- 测测花了 11 年才走到"AI+约束输出"，我们开局就是
- 需要重构的只有局部：个人数据层（localStorage → 可选云同步）在 P2 才动
- 技术债优先级：分享图海报文案模块 > 判词文案池 > 判词/签号视觉一致性（本轮已在修）

## 六、给共创计划的一句话版本

测测证明了"泛心理陪伴"能做成 4500 万用户的生意；我们想证明的是另一件事——**让大模型碰古籍而不编古籍**。这是 AI 时代玄学产品能不能立住的分水岭，也是这个 Demo 存在的理由。
