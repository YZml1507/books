# R46–R50 规划（调研周期 8）

> 调研时间：2026-10-01  
> 依据：无 streak 习惯（SevenGrid/Selfsame/mostly）、隐私优先离线（Weiguru）、
> 身份驱动习惯（Meridius）、 compassionate AI coach 不说教。

## 关键新判断

1. **小满已做对「无 streak」**：没有断签归零、没有罪恶感，下一步是把
   「连续」改成「本周/本月节奏」——进度环、周目标，而非数字惩罚。
2. **AI 教练要「禁用羞辱」**：Selfsame 的 Sage 被 prompt 禁止 shame。
   小满回复里要继续排雷「你不够努力」「别人都在」等词。
3. **数据本地化是护城河**：Weiguru 的 100% offline 是卖点。小满继续
   强化本地优先、可导出、可清除。
4. **身份而非行为**：Meridius 让用户先说「我想成为谁」。小满可以在
   聊天空态或仪式后给一句「你在变成 XXX 的人」式身份反馈。
5. **进度可视化要温和**：色点、进度环、周目标，但不打勾不逼全勤。

## R46–R50 行动

| 轮 | 项 | 内容 |
|---|---|---|
| R46 | 古籍阅读进度记忆 | 古籍/研学页面记住每本书/章节的滚动位置，下次打开回到原位。 |
| R47 | 断签温柔召回强化 | 打卡历史断签 ≥7 天，点击签到后多一句「断几天没关系，今天开张就算数」，不配火。 |
| R48 | 周目标可视化 | 首页或签到区增加本周目标：「本周想打 X 天卡」可设置 3/5/7，显示「还差/已完成」而非 streak。 |
| R49 | 身份反馈句 | 完成仪式/日记/签到后，根据最常问功能给一句身份式总结：「你正在成为会给自己留一口气的人」。 |
| R50 | 古籍问一嘴 | 古籍页每章后加「问小满一句」入口，自动预填上下文 + 引用当前章节。 |

## 不做的事

- 不做 streak、不做 HP/积分、不做排行榜。
- 不做云端同步、订阅墙。
- 不做精确 GPS/天气 API（如 R42 已说明，另排）。
