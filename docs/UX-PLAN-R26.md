# R26–R30 规划（调研周期 4）

> 调研时间：2026-10-01  
> 依据：Character.ai/Replika/Nomi 记忆系统对比、PWA 安装最佳实践、
> Duolingo streak 心理机制、小红书 2026 玄学情绪消费。

## 关键新判断

1. **记忆的下一步不是记更多，而是让用户主动触发**。Nomi/Replika 让
   记忆成为对话入口；小满目前只是把事由列出来，下一步应让芯片
   可点击，直接回聊该主题。
2. **语音要从「功能」变成「陪伴触点」**。Replika 的 voice call 是
    standout；我们已有日签 TTS，下一步覆盖五行人格、解梦结果，
   让多模态朗读成为常态。
3. **PWA 安装需要「显式安装按钮」+ manifest 截图**。浏览器自动
   `beforeinstallprompt` 不够明显，MDN 建议自定义安装按钮。
4. **7 天留存的魔力在「看得见」而非「惩罚」**。Duolingo streak 是
   强驱动，但小满人设温暖低压；应做「轻见面记录」——只显示、
   不催促、不断裂惩罚。
5. **玄学消费正在「护身符化」**。小红书/电商把每日运势/幸运色印成
   挂件、手机壳、头像框；分享图应长出「今日护身符」形态。

## R26–R30 行动

| 轮 | 项 | 内容 |
|---|---|---|
| R26 | 记忆芯片可点击 | 聊天空态 `.chat-empty-memory` 里列出的 3 条事由变成可点 chip，点击后预填 `#chatInput` 并把焦点落入输入框，实现「先聊这个」。 |
| R27 | 语音扩展 | 五行人格结果加 `🔊 读我是哪型`；解梦结果加 `🔊 读给小满听`。共用 `_speak()` 辅助函数。 |
| R28 | PWA 安装引导强化 | manifest 增加 `screenshots`（用已存在的日签/人格海报截图占位或新增静态图），并在首页/设置页显式渲染「📲 加到桌面」按钮（复用 `_deferredInstall`）。 |
| R29 | 今日护身符分享卡 | 新增 `lucky` 海报类型：把日签的幸运色/幸运数/财神方位/贵人属相生成一张竖版「今日护身符」分享图。 |
| R30 | 7 天轻见面记录 | 聊天空态/首页显示「这周小满看见你 X 次」，只计数、不催促、不断裂；数据来源 `usage:*` 足迹。 |

## 不做的事

- 不做 streak freeze/补签/断签惩罚（与小满低压人设冲突）。
- 不做 native widget（PWA 能力边界）。
- 不做语音输入/录音上传（仅 TTS，保护隐私）。
