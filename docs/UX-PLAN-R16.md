# R16–R20 规划（调研周期 2）

> 依据：脑榜《AI陪伴赛道复盘》(2025)、Appbot《40,294 条 Finch 评论分析》、
> Soul《2025 Z世代情绪消费报告》、《2025 年轻人玄学消费报告》、
> CSTAM《陪伴型AI情感设计策略》。

## 调研改了什么判断

1. **AI 情感陪伴大盘在退潮**：猫箱 DAU 半年腰斩、星野下载量跌 80%、
   主流陪伴 app 月均使用 <5 天、次留 20-30%。
   **但 Finch 是例外**（D1/D7=54%/37%，比 Duolingo 高）。
   结论：「聊天陪伴」伪需求，「依恋对象+微任务能量循环」才是真引擎。
   我们已把小满从装饰升级成叙述者（N1），这轮往「循环」再进一步。

2. **陪伴-疏离悖论**（CSTAM 论文）：陪伴型产品应做「辅助性」而非
   「替代性」——帮用户回到真实生活，不替代人际关系。
   我们「不推送/不惩罚/劝回真实世界」的设计恰好是学术共识方向，
   可以写进产品叙事当差异化。

3. **水逆是玄学求助最高峰**（54% 长期水逆时求助、51.7% 失业应急、
   转运珠占玄学消费 50.8%）。我们已有 mercury 态字段但只展示一行——
   水逆期是产品最该「接住人」的时刻，现在接得太平。

4. **Z 世代为「被需要、被看见」付 43.1%**：Finch 的"它需要你"。
   我们的罐子是单向的（用户攒色点）；双向=「你攒的色点小满收着，
   它们也会变成店里的东西」。

5. **仪式感付费意愿 32.3% / 颜值主义 31.1%**：收集层值得做，
   但必须零惩罚（Finch 连 streak 都可暂停/修复）。

## 不做的事（调研约束）

- 不做推送/streak 惩罚（陪伴-疏离悖论 + 我们的人设）。
- 不做云同步（无账号是资产；数据清零风险写进隐私话术即可）。
- 不做付费墙——调研显示陪伴赛道 ARPU 极低，我们产品形态不靠它。
