## 二、跨功能系统性问题（比单点更要命）

### P1 · 信息层序倒置：术语在前，人话在后
全站的通病是「先给术语，再解释」——日签先说「半合」再解释、塔罗先说「权杖A 逆位」再说它意味着什么。**正确序应该永远是人话在前、术语垫后或进折叠**。八字结果页的「小卡层」是全站唯一序对了的地方——把它的写法当成全局模板。

### P2 · 没有「数字」这个通用语言
测测首屏的第一生产力是**分数**：综合分 + 四维度分。「82」不需要任何文化资本就能读懂。我们全站唯一的数字是合拍指数 /99——而最该给分数的日签，给的是一个术语。**缺一个「今天好不好」的零门槛读数**。

### P3 · 导航按「术数类型」分，不按「我的烦恼」分
九宫格是塔罗/八字/合婚/黄历——这是**学科分类**。她累了打开时的脑内状态是「我心里有事/我睡不着/我想知道我俩行不行」——**场景分类**。黄历视图的「我打算：搬家/约会/面试」已经验证场景入口可行，但全站只有它用了这个思路。

### P4 · 缺「一分钟小测试」前门
测测的获客引擎不是排盘，是零门槛趣味测试：MBTI（1170 万人做过）、爱情树（依恋类型）、幸运地图（桃花城市）、pick 卡——**做完即晒、晒完拉新**。我们每个功能都要填表单，没有一个"点一下就出结果"的轻测试。这是我们的获客结构缺口。

### P5 · 留存零件在，闭环没有
签册、许愿瓶、每日打卡、明日预告都在——但彼此不通：打卡不攒任何东西、许愿没有进度、签册只是历史列表。竞品的做法是签到→积分→兑换/成长的闭环。**我们的留存要素彼此不认识。**

### P6 · 情绪场景首屏无接应
她「累/沮丧时打开」——第一屏是表单+九宫格，没有任何一处对她说"我懂你现在的状态"。测测有心情小镇直接把「倾诉」做成首页级入口。我们的聊天（「夜深了睡不着的话我在这儿」）文案已到位，但埋在第九张卡。

### P7 · 表单负担普遍偏重
合婚 12 字段、塔罗 8 牌阵+参数、起名/桃花/六爻都要年月日时。竞品做法是**先用最少输入给一个结果，想要更准再补**（测测合盘先星座后生日渐进）。我们要求前置全量输入。

## 三、改造方案

### 阶段 A · 语言与层序（全站，收益最大成本最低）

**A1 人话先行规范**：所有面向结果的文案改序为「白话结论 → 一句解释 → 术语小字注」。日签卡重排：
```
今日能量 82
半合 · 今天有暗劲帮你 ★★★★☆
下午适合推进那件拖了很久的事，有人搭手
（对你：半合 · 通版吉）· 想看专业依据？▾
```
分数映射确定性给出（吉档→75-95、平→60-80、慎→35-60），同日同人同分。

**A2 术语下沉**：十神/地支/纳音/运算摘要已有折叠，检查所有结果视图保证"首屏无术语、折叠有出处"——可核验人设不破。

**A3 四签人话化**：「许个愿，抽张签带走」→ 攒好运（给今天存点运气）/ 求顺利（考试面试答辩）/ 求喘息（累了就歇会儿）/ 转个运（给最近的倒霉翻篇）。点击后的反馈页顺带说一句这张签"管什么"。

### 阶段 B · 首屏重构（日签卡 + 场景入口）

**B1 今日能量分**：判词盘上方或并入盘内加数字读数。

**B2 三维度小分**：💗感情 / 💼做事 / 💰钱袋各一个 60-95 分+半句人话——数据层六亲/十神映射现成（官鬼=事业、妻财=财、父母=文书），确定性可算。不做五个，三个刚好。

**B3 情绪接应行**：日签卡内「今天有点累？和小满说两句 →」按时段换文案（深夜=「睡不着的话，小满在」），点击直达聊天并自动带一句开场白。

**B4 功能区重排**：九宫格上方加一行场景快捷条——「💭 心里有事 · 🌙 昨晚做梦 · 💞 我俩行不行 · 📅 挑个日子」分别直达 chat/dream/hehun/huangli 并预填语境。学科九宫格保留在下方不动。

### 阶段 C · 单功能逐个收拾

| 功能 | 动作 | 量级 |
|---|---|---|
| 塔罗 | 默认只给「抽一张/抽三张（过去现在未来）/问一件事」三档；牌阵全收进「懂行进阶」折叠；结果首行永远是人话（「别急，这事还没到动的时候」），牌名小字 | 中 |
| 星座 | 年份下拉换成年月日滚轮/输入（修 1900-2018 滚动灾难） | 小 |
| 合婚 | 表单瘦身：必填只留「我俩的年月日」，时辰性别昵称全收「填了更准」折叠；结果第一屏=合拍分数+一句「你们俩的卡点/甜头」 | 中 |
| 命盘 | 把小卡人话层提为唯一首屏；十神表等全部在折叠内（已基本如此，查缺补漏） | 小 |
| 起名 | 风格名加人话副标：「诗经草木 → 像芷若、采薇那种温柔挂」 | 小 |
| 四签/打卡/许愿 | 打通：打卡一次存一颗星→星册可视化→攒满 7 颗解锁一句「小满的话」；许愿瓶加「实现了回来报喜」回访钩 | 中 |
| 每日签 | 「明天预告」已好；给明日预告加半句钩子文案 | 小 |

### 阶段 D · 轻测试前门（获客结构，对标测测 MBTI）

做一个 1-tap 趣味测试当传播钩子，候选（都与现有内核联动）：
- **「你的五行人格」**：填生日 → 直接出「锋利小刀型/温吞大地型」人设卡（命盘引擎现成，八字的小卡层抽出来单独成页）→ 分享图
- **「今天你的幸运签」**：免输入，点一下抽今日签语+开运色——零门槛当日钩
- **「你们俩的星座缘分」**：只选两个星座就出分数（星座速配引擎现成）

共同特征：**不填表单就出结果 + 结果页一张分享图**。测测证明了这类东西是流量入口不是边角料。

## 五、验收口径

改完请同一位反馈者复测，三问：
1. 打开 10 秒内能说出"今天好不好"吗？
2. 每个入口你能不能不看说明就知道点了干嘛？
3. 有没有哪句你会想发给朋友？

另加一条我们的硬标准：**任何结果页首屏零术语，术语只在折叠层且可核验**——这是和测测们拉开身位的线。
