# R41–R45 规划（调研周期 7）

> 调研时间：2026-10-01  
> 依据：Hina/Replika 主动 check-in + 天气感知、BreezyBuddy 本地天气 nudge、
> 微庆祝/Confetti 反馈、PWA 本地通知探索。

## 关键新判断

1. **主动 check-in 是关系感的转折点**：Hina/Replika 2026 都强调
   "reaches out first"，不再被动等用户打开。小满可以基于本地时间/天气
   给问候，但必须在用户主动打开时呈现，不真发 push。
2. **天气感知让问候更具体**：BreezyBuddy 用本地天气给 lifestyle nudge。
   小满首页问候语可以随天气/时段微调（雨天→带伞，晴天→出去走走）。
3. **微庆祝要覆盖更多完成点**：签到、周报、仪式完成后都给一颗星。
4. **周报的下一步是「周总结回流」**：周报海报分享出去后，对方打开
   能看到「TA 的一周小满周报」并引导 TA 也生成自己的。
5. **深色/系统主题跟随**：2026 年用户对系统主题一致性有基本预期。

## R41–R45 行动

| 轮 | 项 | 内容 |
|---|---|---|
| R41 | 签到微庆祝 | 每日打卡完成后也飘一颗 ✨ 星星，与仪式/日记统一反馈语言。 |
| R42 | 天气感知问候 | 首页 welcome 文案增加本地天气词：下雨→「出门记得带伞」、晴天→「今天适合晒晒太阳」；数据用浏览器 geolocation + Open-Meteo（无需 key）或本地占位。 |
| R43 | 周报分享回流 | `?view=weekly&from=share` 到达时显示「看看 TA 的一周 · 你也来一份」入口。 |
| R44 | 系统主题跟随 | 主题切换增加「跟随系统」选项，监听 matchMedia('(prefers-color-scheme: dark)')。 |
| R45 | 主动 check-in 文案 | 聊天空态/首页根据 usage:last 和时段生成「小满想你了」式轻问候，不真 push、只在用户打开时露。 |

## 不做的事

- 不做真实后台 push/定时任务（超出 PWA 权限与隐私边界）。
- 不获取精确 GPS，只粗略天气/城市（可选）。
- 不做付费/订阅墙。
