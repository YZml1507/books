# 后续几轮方案与规划（2026-10-03 全网调研后）

## 调研结论（全网证据）

- **XHS 玄学面**：玄学话题浏览 ~20 亿；「许愿/心愿」搜索年增 200%、笔记发布年增 170%；「接好运」跟帖文化是头部互动形态；文玩女孩 2700 万讨论。用户画像：76.5% 关心事业、74.9% 财运、49.6% 爱情。
- **测测（5000 万用户，85% 女性）**：新方向 = 情绪陪伴 > 算命——AI 心情小镇（6 位虚拟倾听师多人格）、3D 心理沙盘、房树人。「趣味是入口，科学是归途」。
- **赛博好运 CyberLuck（新竞品）** 我们没有的功能：压力粉碎机（写烦恼→视觉粉碎→释放仪式）、决策神谕（替你决定 YES/NO）、运势签摇签、毒舌/治愈双人格、20 维度评分、肯定语卡片收集、小组件/表盘。
- **Co-Star**：阴阳怪气推送 + 社交合盘是留存双引擎——判词风格化能记住。

## 定调

下几轮方向 = **情绪仪式层**（释放/许愿/陪伴的轻仪式）+ **决策工具**（YES/NO 替你决定）——都是纯前端零基建、XHS 已验证的互动形态，与小满「解忧铺」定位同宗。

## 功能方案（优先级排序）

1. **烦恼粉碎机**（最高优先，本轮即做）✅ 已落地（R3335）
   - 写入框「最近压着你的事」→ 粉碎动画（纸条进碎纸机/燃烧字效，CSS+JS canvas 粒子）→ 碎完给一句小满安抚语（池化文案+当日 seed）。
   - 出口：碎完不存档（仪式意义=没了），可选「扔进愿望瓶」转许愿。
   - 入口：首页日卡附近/聊天空态 chip + _CHAT_ACTIONS 路标词（烦恼/压力/焦虑/烦死）。
2. **决策神谕**（次轮）✅ 已落地（R3336，掷筊三态确定性判词）
   - 「帮 TA 做个决定」：输入纠结的事 → 抛筊/硬币动画 → 圣筊/笑筊/阴筊三态或 YES/NO/缓一缓 + 一句小满式判词。确定性=同日同事同签（_hashPick），可晒图。
   - 入口：功能宫格新卡「✋ 替你决定」。
3. **愿望回音**（次轮）
   - 愿望瓶升级：许过的愿可标记「实现了」→ 出一张还愿卡（可晒，接好运文化回流 XHS）；列表页分「在漂的/已如愿」。
4. **肯定语收集册**（储备）
   - 今日咒语点❤️收藏 → 「我的咒语册」格页（复用收藏镜像链）。
5. **摇一摇**（储备，移动 only）
   - DeviceMotion 摇签触发塔罗/求签——仪式成本最低的身体交互；需权限降级为按钮。

## 本轮审计子规划（R3335-R3339，并行 5 个）

- R3335 解梦+塔罗解读内容质量真机审（真 LLM，像真人用户判读质量）
- R3336 情绪功能深审（心情罐/许愿瓶/journal/创可贴 全链路）
- R3337 海报物料视觉复审（壁纸/头像/周报/护身符最新版逐张评）
- R3338 性能预算终扫（LCP/TTI/bundle/字体/图片全量预算对账）
- R3339 数据面终扫（备份导入/镜像/wipe/GC 边界复出）
